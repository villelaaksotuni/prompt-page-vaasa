# Prompt Page

A small project for collecting, testing, and showing prompts in a clean page format.

## What this is

Prompt Page is a simple repo for a prompt-focused page where ideas, experiments, and good prompts can live in one place.

## Why it exists

Because good prompts deserve better than being lost in random notes, half-finished tabs, or a document called `final_final_v2_really_final`.

## Features

- A focused home for prompts
- Easy to expand and customize
- Good starting point for experiments
- Slightly more organized than pure chaos

## Getting started

Clone the repo:

```bash
git clone https://github.com/villelaaksotuni/Prompt-page.git
cd Prompt-page
```

Then open the project and start building.
